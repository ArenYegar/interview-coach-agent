# 演示与话术脚本（3 分钟版）

## 0:00-0:30 是什么
"这是我给自己做的求职陪练 Agent。给它一份 JD 和我的简历，它会先做岗位要求对齐，然后用状态机跑一场模拟面试：
出题、追问、评分，最后给我一份复盘和跨场次弱点画像。"

## 0:30-1:20 演示（终端）
```powershell
python run_demo.py --jd data/jd_sample.md --resume <我的简历.docx> --questions 5 --interactive --eval
```
边跑边说三句：
1. "现在在做的每一步都有 trace：`runs/<run_id>/trace.jsonl`，出问题能定位到具体工具调用"
2. "评分有两个来源：规则的要点覆盖率 + 模型语义分，`method` 字段会标出来，所以能对照"
3. "跑完自动出指标：覆盖率、工具成功率、要点覆盖率；人评一致性我留给自己填，不填就显示 pending"

## 1:20-2:20 讲取舍（面试官最爱问的三点）
- **为什么状态机**：中断恢复 + 人机协同 + 可回放，黑盒 AgentExecutor 三条都做不到
- **模型挂了怎么办**：解析失败先让模型自修，仍失败退回规则分；链路不中断，降级记进 trace
- **指标怎么保证不注水**：所有指标可从 `results/*.json` 直接算；人评没填就 pending，不写"提升 X%"

## 2:20-3:00 亮差异点
- 跨场次弱点追踪：SQLite 里同一弱点在多场重复出现 → 标 high，直接告诉我该练什么
- 覆盖优先选题：先保证每条硬性要求有对口题，再平衡类别（覆盖率从 0 提到 0.8 的过程有 commit 可查）
